# Club Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the “DIU SEC” text branding in the public header and footer with the club’s supplied logo image.

**Architecture:** Copy the user-supplied PNG from `images/` (not served by Next) into `public/`, then swap the brand label in the two public shell components for a fixed-dimension `<img>` following the repo’s existing image pattern. No shared component is warranted for two one-line usages.

**Tech Stack:** Next.js App Router, TypeScript strict, Tailwind CSS, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-27-club-logo-design.md`

## Global Constraints

- Public header and footer only; admin sidebar, ID-card canvas, and copyright line stay unchanged.
- No new dependency, no new animation, no server/data changes.
- `images/sec_logo.png` is user-supplied and must not be modified; copy it to `public/sec_logo.png`.
- Plain `<img>` with explicit `width={82}` / `height={40}` and the repo’s `eslint-disable-next-line @next/next/no-img-element` pattern; do not add `next/image`.
- Alt text is exactly `DIU SEC` so the header home link keeps its accessible name.
- Mobile-first: no horizontal overflow at 360px; keyboard focus ring on the home link stays intact.
- Every task ends with `pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm e2e && git diff --check`.
- E2E needs env sourced first: `set -a; . ./.env; set +a; pnpm e2e`.

## Review Focus

- **Asset 404 / wrong path:** the image must actually load, not just carry a `src` attribute — Task 1 asserts `naturalWidth > 0` and `src === "/sec_logo.png"` in both header and footer.
- **Screen reader loses the home link name:** removing the text must not leave an unnamed link — Task 1 asserts `toHaveAccessibleName("DIU SEC")` and no remaining exact-text brand label.
- **Dark-mode contrast:** the logo blue is ~2.3:1 on the dark header — Task 1 injects `.dark`, asserts the image wrapper computes to `rgb(255, 255, 255)`, then removes the class.
- **Layout shift at first paint:** an unsized image would push the header down — Task 1 asserts explicit `width`/`height` attributes, and the existing CLS test in `e2e/home.spec.ts` stays green.
- **360px overflow from a wider image:** the logo must fit beside the menu button and Join Now CTA — Task 1 asserts `document.documentElement.scrollWidth <= innerWidth` in the default 360px viewport.

- [ ] **Step 2: Write the failing e2e test**

Add to `e2e/home.spec.ts`:

```ts
test("uses the club logo instead of text branding in the public shell", async ({ page }) => {
  await page.goto("/", { waitUntil: "networkidle" });

  const headerLogo = page.locator("header a[href='/'] img");
  const footerLogo = page.locator("footer img");
  for (const logo of [headerLogo, footerLogo]) {
    await expect(logo).toBeVisible();
    await expect(logo).toHaveAttribute("src", "/sec_logo.png");
    await expect(logo).toHaveAttribute("alt", "DIU SEC");
    await expect(logo).toHaveAttribute("width", "82");
    await expect(logo).toHaveAttribute("height", "40");
    expect(await logo.evaluate((el: HTMLImageElement) => el.naturalWidth)).toBe(82);
  }

  await expect(page.locator("header a[href='/']")).toHaveAccessibleName("DIU SEC");
  await expect(page.getByText("DIU SEC", { exact: true })).toHaveCount(0);
  expect(await page.evaluate(() => document.documentElement.scrollWidth <= window.innerWidth)).toBe(true);

  await page.evaluate(() => document.documentElement.classList.add("dark"));
  const chip = await headerLogo.evaluate((el) => getComputedStyle(el.parentElement!).backgroundColor);
  expect(chip).toBe("rgb(255, 255, 255)");
});
```
