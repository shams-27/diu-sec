# DIU SEC — Website Requirements

Daffodil International University Software Engineering Club (DIU SEC). Source of truth for the public website. Original PDF archived in `docs/archive/`.

## 1. Core Website Modules

| ID | Module | Functional Requirements & Features |
|----|--------|-------------------------------------|
| 01 | Intro Section | Club mission, manifesto, key impact metrics (1,200+ members, 25+ hackathons, 80+ workshops, 150+ projects), and quick CTAs (Calls to Action). |
| 02 | Committee Section | Filterable Executive Committee directory by session/year (2026, 2025, etc.) displaying roles, batch numbers, and social profiles. |
| 03 | Wings, Members & Roles | Dedicated engineering wings — Competitive Programming, Web & Mobile Development, AI/ML (Artificial Intelligence / Machine Learning), Cyber Security & DevOps (Development & Operations), and UI/UX (User Interface / User Experience) — listing Wing Leads, Core Members, and specific responsibilities. |
| 04 | Membership Apply | Online registration form validating DIU SWE (Software Engineering) Student IDs (XXX-35-XXX) and institutional emails (@diu.edu.bd), generating an instant Digital Member ID (Identification) Card upon submission. |
| 05 | Events & Courses Section | Upcoming and past hackathons, workshops, and multi-week skill courses with syllabi modals, live seat counters, and seat reservation. |
| 06 | Magazine Section | Digital club publications, tech newsletters, student-written technical articles, and downloadable PDF (Portable Document Format) issues. |
| 07 | Hall of Fame | Spotlight archive honoring ICPC (International Collegiate Programming Contest) and NCPC (National Collegiate Programming Contest) finalists, national hackathon champions, GSoC (Google Summer of Code) contributors, and distinguished alumni. |
| 08 | Student-Built Projects | Filterable open-source repository showcase featuring live demos, tech stacks, student contributors, and GitHub links. |
| 09 | Certification & Verification | Public credential lookup portal (DIU-SEC-CERT-XXXX) supporting QR (Quick Response) code verification and downloadable certificates for workshops, courses, and executive roles. |
